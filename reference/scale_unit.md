# Position scales for units data

**\[deprecated\]** These are the default scales for the units class.
These will usually be added automatically. To override manually, use
`scale_*_unit`.

## Usage

``` r
scale_x_unit(...)

scale_y_unit(...)
```

## Arguments

- ...:

  Passed on to
  [`units::scale_x_units()`](https://r-quantities.github.io/units/reference/scale_units.html)
  or
  [`units::scale_y_units()`](https://r-quantities.github.io/units/reference/scale_units.html)
